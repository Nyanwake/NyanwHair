# NyanwHair 0.35.42 (preview)

Аддон Blender для создания стилизованных полигональных волос. Редактируйте управляющий каркас из точек и рёбер, наблюдайте результат в Live-предпросмотре и создавайте независимый Mesh для дальнейшей работы.

## Установка

1. Скачайте **NyanwHair_v0.35.42_Isolation.zip** по ссылке в [релизе v0.35.42](https://github.com/Nyanwake/NyanwHair/releases/tag/v0.35.42). Распаковывать ZIP не нужно.
2. В Blender откройте **Edit → Preferences → Add-ons → Install from Disk…** и выберите этот ZIP.
3. Включите **NyanwHair**. Панель находится в **3D View → N → NyanwHair**.
4. После обновления существующей установки перезапустите Blender.

Заявленный минимум — Blender 5.1. Выпуск проверен в Blender **5.2.3 LTS, OpenGL**. Проверка всех GPU и остальных графических API не проводилась.

## Начало работы

Создайте новый локон кнопкой панели. В Edit Mode перемещайте точки и редактируйте каркас обычными средствами Blender. Каждый сегмент имеет две направляющие и два края; край может быть ребром или одной точкой. Метки начала и конца задают направление построения поверхности.

В настройках сегмента доступны детализация, ширина, выпуклость и распределение. Сглаживание и локальная плотность настраиваются на выделенных точках и направлениях. Один объект может содержать несколько независимых групп с собственным цветом и связанным Mirror.

В Object Mode сверху расположена увеличенная кнопка «Создать новый локон», затем разделитель и увеличенная кнопка преобразования. Для получения обычной геометрии нажмите **«Преобразовать в Mesh»**. Будет создан отдельный объект; управляющий каркас останется доступен для дальнейшего редактирования. Цвет группы служит для предпросмотра. UV создаётся вместе с Mesh; материалы и текстуры настраиваются отдельно.

## Возможности

- Плавные пряди из редактируемого каркаса, общие направляющие и согласование сетки соседних сегментов.
- Локальное уплотнение вокруг управляющих точек с плавным переходом.
- Умное вытягивание нескольких свободных краёв, раскрытие точечного края и боковые ответвления.
- Объёмное ответвление E-Face из двух противоположных рёбер с открытым верхом и согласованием ширины у основания.
- Построение каркасной кривой через E с промежуточными точками, назначение краёв, Merge и Hair Loop.
- Независимые группы, связанное отражение по локальным осям объекта и обратная сторона сегмента со своими шириной и выпуклостью.
- Шесть тем, MatCap/Studio/Flat по текущему виду, настраиваемая сетка, подсветка и скрытие вспомогательных элементов.
- Сглаживание поверхности с Sharp по направляющим и создание независимого Mesh.

## Быстродействие Live

Несвязанные части каркаса внутри одной группы сохраняют отдельные результаты расчёта и буферы предпросмотра. При перемещении точки небольшого независимого локона остальные части переиспользуются. Опорный физический масштаб группы сохраняется, а детализация рассчитывается по собственным направляющим сегмента. Изменение детализации отдельного локона не перестраивает сетку соседнего. На общем физическом ребре используется более плотное значение его владельцев. Свободная поперечная ветка не задаёт плотность основной пряди; стыки и переходы продолжают согласовываться.

Повторяющиеся схемы дискретизации, сборки полигонов и индексы GPU кэшируются, а подготовка атрибутов выполняется массивами. Это не уменьшает детализацию во время движения. Скорость зависит от связности каркаса, плотности, обратной стороны, видимости обычных объектов сцены и GPU. Для неоднозначных входных данных сохраняется полный путь расчёта.

## Работа рядом с другими инструментами

Горячие клавиши действуют только на активном каркасе NyanwHair в Edit Mode. Обычный меш не проходит проверку операторов; колесо и его сочетания остаются доступными Blender и другим аддонам. В сцене без видимых волос обработчик предпросмотра не создаёт шейдеры и не меняет состояние GPU.

Live обновляет только активный редактируемый объект волос. Остальные отображают готовую поверхность без направляющих, точек и сетки. При первом открытии файла или восстановлении удалённого объекта один раз подготавливается кэш, необходимый для его показа. Обычные изменения и Undo/Redo другого меша не перестраивают фоновые волосы. Состояние отрисовки GPU после собственного прохода восстанавливается.

## Mirror в предпросмотре

Отражения используют одну исходную геометрию и GPU-буферы с разными матрицами. Нормали, сетка на швах и выбор исходной половины сохраняются. Две оси дают до четырёх экземпляров, три — до восьми; их отрисовка всё равно требует времени GPU. Редактируется исходная половина. Для проверки видимости точек используется один BVH исходной поверхности с отражёнными лучами.

При частично совпадающих с плоскостью зеркала гранях сохраняется прежний CPU-путь, чтобы не изменить правила удаления дубликатов и сглаживания сложных швов. Полностью лежащая в плоскости ось, не добавляющая геометрию, пропускается. Создание Mesh и UV использует прежнюю сваренную геометрию; оптимизация относится к Live-предпросмотру. Параметры Mirror групп и рабочая сцена не получают новых модификаторов.

## UV

При нажатии «Преобразовать в Mesh» создаётся активная **UVMap**. Острова ориентированы сверху вниз: начало локона выше, конец ниже. Плавно сходящиеся сегменты объединяются, если их границы и направления совместимы и сшивание не создаёт перекрытий или заметного дополнительного растяжения. Резкие ответвления, разные группы, лицевая и обратная стороны получают отдельные острова. Границы островов помечаются Seam только на готовом Mesh.

Под полноразмерной кнопкой «Преобразовать в Mesh» находятся **UV** и **Mirror UV**. UV включает создание развёртки; Mirror UV доступен при включённом UV и отражении хотя бы одной группы. Без Mirror галочка остаётся видимой и неактивной. По умолчанию обе включены. Режимы Mirror UV:

- **Включено** — отражение использует UV оригинала, острова накладываются точно.
- **Выключено** — отражения упаковываются как отдельные острова.

UV отключается галочкой под кнопкой «Преобразовать в Mesh». Угол сшивания находится под галочками UV в Object Mode и виден только при включённом UV. Для новых объектов он равен 60°; сохранённые настройки существующих объектов остаются своими. Больший угол не принуждает к сшиванию несовместимых границ. Расчёт выполняется только при создании Mesh и не замедляет перемещение точек в Live. Полосы сохраняют общий масштаб текстуры приблизительно; искривлённая поверхность и сужение кончика могут давать растяжение. Это первый preview UV, рассчитанный на дальнейшую проверку в работе.

## Горячие клавиши

Действуют в Edit Mode на каркасе NyanwHair.

| Клавиша | Действие |
| --- | --- |
| **E** | Удлинение края или создание ответвления по выделению |
| **E из одной свободной точки → колесо** | Зафиксировать конец кривой и задать число промежуточных точек; мышь меняет изгиб |
| **Ctrl+R** | Hair Loop: предпросмотр и создание направляющей или опоры |
| **M** | Merge с сохранением настроек и краёв NyanwHair |
| **Ctrl+Shift+колесо** | Детализация выбранных сегментов, шаг 1 |
| **Shift+колесо** | Ширина выбранных сегментов |
| **Ctrl+колесо** | Выпуклость выбранных сегментов |
| **Alt+колесо** | Сглаживание выбранных направлений с шагом 0,1 |
| **ЛКМ / Enter** | Подтверждение активного инструмента |
| **ПКМ / Esc** | Отмена активного инструмента |

При интерактивном вытягивании доступны X/Y/Z и числовой ввод. Состав действия E зависит от выделения; без выделения геометрия не изменяется.

## Библиотека тем

Палитры находятся в **themes.json** рядом с palette.py. Цвета записаны как sRGB HEX: `surface` — цвет группы по умолчанию, `segment` — цвет подсветки сегмента, `guide` — направляющие, `selection` — выбранные рёбра и точки, `point` — обычные точки, `outline` — контур точек. `strength` задаёт начальную силу подсветки; сохранённый пользователем ползунок имеет приоритет. Активная точка остаётся белой, начало и конец сохраняют семантические цвета. Цвет сетки автоматически вычисляется из текущего цвета группы: темнее и насыщеннее, с прежним ползунком прозрачности.

Чтобы добавить тему, скопируйте запись в массиве `themes`, укажите уникальный `id` латинскими заглавными буквами, уникальный целый `value` от 6, имя и цвета. Существующие `id` и `value` не переименовывайте: они сохраняются в файлах Blender. После правки перезапустите Blender. Явно заданные пользователем цвета групп остаются своими. Некорректная библиотека включает запасную палитру и печатает причину в консоль; проверяйте синтаксис JSON и уникальность идентификаторов. При обновлении аддона сохраните свою копию themes.json.

## Ограничения preview

Каркас должен описывать осмысленные полосы и соединения. Инструмент не является универсальной ретопологией произвольных пересекающихся поверхностей; для сложных замкнутых и противоречивых соединений может потребоваться ручная подготовка. Самопересечения при любом расположении точек автоматически не исключаются.

Материалы и цветовые текстуры волос автоматически не создаются. Предпросмотр не заменяет полноценный материал итогового объекта.

Очень маленький Clip Start при большом диапазоне Clip Start/End уменьшает точность буфера глубины, особенно в перспективе. Используйте диапазон, соответствующий масштабу сцены. Для больших причёсок скорость зависит от числа сегментов, связей, детализации и GPU; универсальная частота кадров не заявляется.
