# NyanwHair 1.01

Каркас хранится в обычном Mesh Blender. Сегменты, торцы, плотность и сглаживание задаются атрибутами каркаса. Live строит поверхность; преобразование в Mesh создаёт независимый результат с UV, Sharp и Seam по направляющим.

Обратная сторона создаётся только явной одноразовой командой. Копия состоит из обычных сегментов с собственными точками; свободные края можно соединить дополнительными сегментами. Генератора процедурного объёма и локальной толщины больше нет. Старые каркасы открываются; прежние атрибуты объёма не участвуют в расчёте.

E различает точный выбор торца, непрерывную цепочку рёбер, отдельное ребро, одиночную точку и E-Face. Открытая цепочка создаёт одну полосу, замкнутая — две. Непригодная операция откатывается до изменения исходного каркаса.

Группы независимы. Неактивные волосы используют готовый предпросмотр. Mirror отображается экземплярами GPU; UV рассчитывается только при создании Mesh. Корректные UV-острова сохраняются, сложенные проходят локальное расправление с проверкой ориентации треугольников.

Библиотека цветов хранится в themes.json. Интерфейс EN / RU; поддерживается Blender 5.1+.
