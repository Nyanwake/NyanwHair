# NyanwHair 1.09

Каркас хранится в обычном Mesh Blender. Live строит поверхность; преобразование создаёт независимый Mesh с UV, Sharp и Seam по направляющим.

Новый локон использует общий стартовый шаблон для объектов и групп. E различает торец, цепочку рёбер, одиночную точку, ветвление и целые сегменты. Целый локон получает замкнутую редактируемую обратную сторону; вытягивание участка существующей оболочки сохраняет верхнюю поверхность.

Боковины E создаются цельными продольными сегментами, включая начало интерактивной операции с нулевой толщиной. Направленное сглаживание соединений по толщине равно 0 с обоих концов. E на свободной цепочке точек или рёбер создаёт сегмент.

Обратная сторона создаётся одноразово. Лицевой сегмент сохраняется, задний делится своей центральной направляющей на два. Смещение и выпуклость меняют предпросмотр диалога; отмена возвращает исходный каркас. «Соединить края» соединяет боковые направляющие, при нулевом смещении без стенок. Торцы остаются открытыми.

Заголовки разделов переключают режимы 3/2/1. В режимах 1 и 2 выбор всех точек сегмента выделяет сам сегмент; режим 3 позволяет выбирать лицевую и задние грани независимо. V разделяет краевой угол редкого каркаса; для обычных вееров граней работает Rip Blender. Группы независимы; неактивные волосы используют готовый предпросмотр.

Mirror отображается экземплярами GPU. Допуск слияния применяется к расчётным координатам без записи в исходный Mesh при обычном Live. Явная команда M → Mirror ставит выбранные точки на плоскость; E и создание обратной стороны учитывают этот шов. В преобразованном Mesh отражения используют общие вершины шва.

UV рассчитывается при создании Mesh. Корректные острова сохраняются, сложенные проходят локальное расправление с проверкой ориентации треугольников. Библиотека цветов — themes.json; интерфейс EN / RU. Blender 5.1+.

Торцы сохраняют продольное положение при настройке выпуклости. Общий край встречных поверхностей не получает дополнительного выгиба; плавное сопряжение и жёсткие нормали на таком шве устраняют складку у обратной стороны. Активный раздел интерфейса выделяется общей рамкой. Новые объекты и локоны в пустых группах создаются у 3D-курсора.

Значки режимов окрашены по теме аддона; ресурсы кэшируются и освобождаются при отключении. Обратная сторона поверхности затемнена в шейдере. «Перевернуть нормали» под локальной плотностью изменяет ориентацию выбранных сегментов, сохраняя форму через компенсацию знака выпуклости. Старый флаг профиля читается для совместимости; автоматическое согласование обхода соседей работает до явного переворота.

Пресет шапки содержит пользовательский каркас и Mirror X. Выгиб использует обычный синусный профиль с одной расчётной поправкой на сегмент по углам боковых соседей. Отдельного режима нет; выпуклость регулируется поверх поправки в обе стороны. Прямые соединения по толщине сохраняются. При Loop выгиб переносится в новую направляющую. Плавные поперечные стыки не получают Sharp; Seam на направляющих сохраняется. E вытягивает внутренние рёбра и несколько цепочек с общей исходной базой; два противоположных ребра сохраняют сценарий ответвления из середины.

Режимы 3/2/1 используют кнопки двойной высоты; значки крупных действий окрашены по теме. Mirror → Применить дублирует каркас активной группы по включённым осям, соединяет совпадающие вершины на плоскостях в пределах допуска Merge и отключает оси. Направленные веса, границы и настройки сегментов сохраняются; остальные группы не дублируются.

Выбор объекта кликом по Live-поверхности работает в Object Mode с Shift, Mirror, видимостью и обычными перекрывающими мешами. Голубая заливка штатного Retopology overlay отключается явной кнопкой в «Дополнительно»; остальные оверлеи не меняются.
